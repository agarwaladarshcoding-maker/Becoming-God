# templates

Reusable templates for this repo. Copy, don't edit in place.

- `day-log.md` — daily log entry, used in `ml/day-logs/`, `agentic/day-logs/`, `system-design/day-logs/`.
- `design-doc.md` — system design writeup, used under `system-design/`.
- `project-brief.md` — required before starting any project under `Projects/`. See `Projects/README.md` for the outcome rule.
