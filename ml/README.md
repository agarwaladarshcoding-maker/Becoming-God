# ml

Machine learning study track: notes, small builds, and daily logs. This track is
separate from `AI-ML/`, which holds the existing day-by-day notebook exercises;
`ml/` is for topic-organized notes and standalone builds that come out of that work.

- `notes/` — topic notes (not tied to a single day).
- `builds/` — small standalone implementations (e.g. an algorithm from scratch).
- `day-logs/` — daily log entries for this track, one file per day using `templates/day-log.md`.
