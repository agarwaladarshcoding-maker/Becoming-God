# Projects

- `weekly/` — one folder per week (`week-01/`, `week-02/`, ...).
- `major/` — one folder per major project.

## The outcome rule

Every project folder MUST have a `project-brief.md` with a filled-in OUTCOME field
before any code is written. The outcome must be externally checkable by someone who
isn't me: a live URL, a published benchmark table from a real eval run, a merged PR,
or a demo recording under 90 seconds. "The code works" is not an outcome.

If a project is ever started without an outcome declared, that is a mistake — stop
and declare the outcome before continuing.
