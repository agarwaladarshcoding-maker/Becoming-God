# agentic

Agentic systems study track: notes, small builds, and daily logs — tool use,
multi-agent orchestration, MCP, agent evals.

- `notes/` — topic notes (not tied to a single day).
- `builds/` — small standalone implementations (e.g. a minimal agent loop, a tool-use harness).
- `day-logs/` — daily log entries for this track, one file per day using `templates/day-log.md`.
