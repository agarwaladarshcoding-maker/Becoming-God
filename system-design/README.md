# system-design

System design study material and writeups.

- `fundamentals/` — core concepts (scaling, consistency, caching, queues, etc.).
- `lld/` — low-level design exercises (class diagrams, OOP design problems).
- `hld/` — high-level design writeups for classic distributed systems problems.
- `ml-system-design/` — system design applied to ML pipelines (training, serving, feature stores).
- `ai-system-design/` — system design applied to LLM/agentic systems (RAG, agent orchestration, eval infra).
- `day-logs/` — daily log entries for this track, one file per day using `templates/day-log.md`.

New design writeups use `templates/design-doc.md`.
